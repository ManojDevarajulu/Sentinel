Technical Specification

Sentinel Architecture Blueprint

The closed-form mathematical principles and invariant algorithms powering the engine.

1. Deterministic Reverse-BFS Transitive Blast Radius

Given a set of modified files $M \subset V$, Sentinel constructs the transpose graph $G^T = (V, E^T)$ and evaluates the transitive reachability:

Reach(M) = { v ∈ V | ∃ path v →* m for some m ∈ M }

Hop distance $d(v, M)$ is computed via single-pass BFS. Any propagation path terminating at an Entrypoint or Middleware escalates the audit to CRITICAL.

2. Weighted Architectural Risk Formulation

The risk score $S \in [0, 100]$ is evaluated as a convex combination of 4 architectural invariants:

Score = 0.40 * VolumeScore + 0.30 * CriticalTypeScore + 0.20 * PageRankAvg + 0.10 * ProximityScore

Special rule: If NodeKind.MIDDLEWARE is in the reachability set, Score = max(Score, 85.0) and level is forced to CRITICAL.
